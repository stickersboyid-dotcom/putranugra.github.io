# putranugra.com

Personal site of Nugraha Putra — Product Designer.

🔗 **[putranugra.com](https://putranugra.com)**

## About

A personal space to showcase selected work, writing, and reading — built as
a bento-style layout inspired by [Figma](https://www.figma.com/design/nUlw1ujOzyA5ikqsUj2IFE/Exploration).

- **Home** — a curated mix of projects, writing, reading, and hobbies
- **Project** — case studies from past product design work
- **Writing** — published & unpublished essays
- **Reading** — a running list of books

## Stack

Plain HTML, CSS, and JavaScript. No framework, no build step, no
dependencies — just static files served directly by GitHub Pages.

## Development

```bash
py -m http.server 5173
```

Then open `http://localhost:5173`.

See [DEVELOPMENT.md](DEVELOPMENT.md) for the full folder structure, design
tokens, component reference, and content-editing guide.

## Deployment

Hosted on GitHub Pages with a custom domain (`CNAME`). Pushing to `main`
deploys automatically.
